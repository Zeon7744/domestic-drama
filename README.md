# 国产短剧引擎

针对抖音/快手生态优化的 AI 短剧创作工具。

## 特性

- 🎬 竖屏 9:16 格式适配
- 🗣️ 方言语音合成支持
- ✅ 平台审核规则检查
- 🔥 热门题材推荐库
- ⚡ 批量生成流水线

## 热门题材

| 类别 | 热门关键词 |
|------|-----------|
| 都市 | 霸总、逆袭、复仇、闪婚、职场、豪门 |
| 古装 | 穿越、宫斗、权谋、神医、修仙 |
| 悬疑 | 推理、侦探、刑侦、密室 |
| 甜宠 | 暗恋、破镜重圆、先婚后爱 |

## 使用

```bash
python drama_engine.py "霸总"
python drama_engine.py "穿越" --platform kuaishou
```

## 平台规范

### 抖音
- 单镜头最长 30 秒
- 前 3 秒必须有冲突或悬念
- 禁用词：赌博、暴力、低俗、政治敏感

### 快手
- 单镜头最长 45 秒
- 前 5 秒需要强刺激
- 禁用词：封建迷信、赌博、色情暗示
